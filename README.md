# DeepTab - Effective Neural Networks on Tabular Data

This repository serves as the central hub for **DeepTab — Effective Neural Networks on Tabular Data**, a research project focused on developing and investigating effective neural approaches for learning from tabular data.

DeepTab explores methods for improving how neural models represent, retrieve, and exploit information from tabular datasets, with the goal of making neural approaches more effective and competitive across a wide range of tabular learning problems.

The code and experiments associated with individual research works are maintained in dedicated repositories listed below.

## Research Repositories

### Adaptive Multi-view Neighborhood Retrieval

**Beyond Single Representation Space: Adaptive Multi-View Neighborhood Retrieval for Tabular Learning**

An adaptive neighborhood retrieval method that combines multiple representation spaces to improve nearest-neighbor selection for tabular learning.
